# Exactly Three Single-Amplification Cycles in GCD-Augmented Fibonacci Recurrences

Reproduction code for

> Hawarey, M. (2026). Exactly Three Single-Amplification Cycles in GCD-Augmented Fibonacci Recurrences. *AIR Journal of Mathematics and Computational Sciences* (submitted).

`reproduce.py` recomputes every numerical result of the paper, Tables 1 and 2, and Figure 1 (`figure1.png`), using exact integer arithmetic.

```
pip install matplotlib
python reproduce.py
```

Runtime: under a minute.
